# 迁移依赖规划器（Migration Dependency Planner）

一个从零实现的 Go Web 服务：登记数据库迁移节点（前置依赖、互斥资源、预计时长、
可回滚性、输入/输出 schema 指纹），生成稳定的可执行波次，解释每个节点入波或被阻塞的
原因，并支持逐步执行、模拟崩溃恢复、输出指纹漂移判定与带边界的回滚计划。

- 不接入任何真实数据库；所有数据写入项目目录下的追加式事件日志 `data/events.jsonl`。
- 历史计划以节点快照整体保存，之后修改节点定义不会改写历史计划。
- 同一执行结果携带相同幂等键重复提交只记录一次。

## 构建与演示

```bash
go build ./...
go test ./... -count=1
go run ./cmd/server --addr 127.0.0.1:5222
```

然后访问 <http://127.0.0.1:5222>，页面标题为“迁移依赖规划器”。首次启动会播种 4 个
演示节点（创建索引 → 回填 → 切读 → 删除旧索引，其中删除旧索引不可回滚）。

可选参数：

- `--addr` 监听地址，默认 `127.0.0.1:8080`
- `--data` 事件日志目录，默认 `data`

## 规划规则

- **环检测**：依赖图有环时拒绝规划，并返回一条具体环路（首尾相同），如
  `a -> b -> c -> a`。
- **波次**：同一波次内节点可并发；波次严格按依赖层级推进。同波次节点按 ID 稳定排序，
  输入相同则波次划分与排序完全确定。
- **互斥资源**：共用同一互斥资源的节点绝不会落在同一波次；按（层级, ID）稳定顺延。
- **维护窗口**：起止时间按所选 IANA 时区解释；逐波次累加时长，结束时间等于窗口结束
  视为恰好可容纳（端点包含）。从首个溢出波次起，该波次及其后全部节点进入阻塞。
- **schema 指纹链**：根节点的输入指纹必须等于所选起始指纹；非根节点的输入指纹若与其
  前置声明的输出指纹不一致，则该节点及其整条后继链阻塞。
- **解释**：每个节点都给出入波原因（依赖、互斥顺延、计划时间段）或阻塞原因。

## 执行与恢复

节点状态：`未开始 / 运行中 / 成功 / 失败 / 已回滚 / 需要人工接管`。

- 事件全部追加保存（启动、成功、失败、回滚、崩溃模拟）。
- **崩溃恢复**：从事件日志重放。崩溃时仍在运行的节点标记为“中断”，恢复后可安全重跑；
  已经成功且实际输出指纹与计划声明匹配的节点不得重跑；实际输出指纹与声明不符即判定
  **指纹漂移**，该节点转为“需要人工接管”，其整条后继链阻塞。
- 失败后只能前滚（修正后重试），或为该失败节点生成回滚计划。

## 回滚计划边界

回滚计划只包含失败节点的、**已执行且声明可回滚**的祖先，按拓扑逆序排列。遇到第一个
“已执行但不可回滚”的祖先时**明确停止**：该节点及其之前的节点都不进入计划，
`complete=false` 并用 `boundary` 说明停在哪个节点，绝不给出看似完整的方案。

## HTTP API

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/` | 单页界面 |
| GET | `/api/state?plan=<id>` | 当前节点、计划列表、选中计划的波次/状态/事件 |
| POST | `/api/nodes` | 新增或更新节点（更新不影响历史计划快照） |
| POST | `/api/nodes/delete` | 删除当前定义中的节点 |
| POST | `/api/plans` | 生成波次；有环时返回 `{cycle:[...]}` |
| POST | `/api/execute` | `action=start|succeed|fail`，支持 `idempotencyKey` |
| POST | `/api/crash` | 模拟服务进程崩溃 |
| POST | `/api/rollback/plan` | 生成带回滚边界的回滚计划 |
| POST | `/api/rollback/step` | 按逆序执行单个回滚步骤，支持幂等键 |

## 代码结构

- `internal/model`：领域模型与事件类型
- `internal/planner`：校验、环检测、稳定波次调度、窗口与指纹判定
- `internal/execute`：事件重放、指纹漂移/恢复推导、回滚计划
- `internal/store`：JSON-lines 追加事件日志与幂等去重
- `internal/web`：HTTP 服务与内嵌单页前端
- `cmd/server`：入口与演示数据播种

## 测试覆盖

`go test ./... -count=1` 覆盖：具体环路路径、互斥资源不并发、窗口端点包含与溢出、
稳定调度、输出指纹漂移阻塞后继链、部分执行/崩溃恢复、不可回滚祖先边界（含中间边界
只保留更晚步骤）、以及幂等键重复提交只记一次（含重启后仍生效）。
